维护入口：`code.html` 的摄影区域，每个 `.photo-link` 使用 href 指定大图、img 指定展示图，data-title / data-caption 指定大图浏览文案。添加同结构的 figure 后，浏览器会自动纳入大图切换；页头的数量与主图编号文案需同步修改。样式在 `css/photography.css`，交互在 `js/photography.js`。

按作品系列管理资源，原始文件名不变。`selected/` 为现有精选，`together/` 为本次系列。目录迁移均校验 SHA-256，未修改原图。

放映室结构位于 `code.html` 的 `.photo-screening`。添加作品时同步添加 `.screening-slide` 和对应 `.screening-thumb`，两者顺序保持一致，并更新静态首屏总数及系列说明。标题和描述从 slide 的 data-title / data-caption 读取。大图浏览自动包含两组共 10 张作品。

交互入口为 `js/screening.js`：停留 6000ms，叠化时长在 `css/photography.css` 中为 900ms；提前解码待显示图片，失败时保留上一张并暂停。离开可视区、切到后台或打开大图时暂停计时，返回后重新计时。键盘操作暂停自动播放；系统开启减少动态效果时默认不自动播放，切换不带过渡。原图的标识、署名和构图均保留。
