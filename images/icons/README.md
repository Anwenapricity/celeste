# 图标来源

- `github.svg`、`chatgpt.svg`：Simple Icons 11.15.0 的 GitHub、OpenAI 品牌图标（CC0），分别用于 GitHub 与 ChatGPT 首页入口。来源：https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/github.svg 和 https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/openai.svg 。品牌商标归各自所有者。
- `douyin.svg`、`bilibili.svg`、`xiaohongshu.svg`：本项目绘制的平台识别图形／文字标记。

使用本地 SVG，不依赖运行时图标 CDN。页脚两枚图标通过 CSS 调整显示明暗。
